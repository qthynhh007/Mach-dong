Bản thử nghiệm mô phỏng lúa OM5451, Windows 64-bit.

Tải **MachDong.exe** trong Assets, nhấp đúp để chạy. Giao diện mở trong trình duyệt; đóng cửa sổ Mạch Đồng để thoát. Không cần cài Python hay AI cục bộ. Cần Internet để mô phỏng và lấy dữ liệu.

Dữ liệu và engine chạy trên máy chủ dùng chung. Groq với model `openai/gpt-oss-20b` đã được kích hoạt: trong tab Mô phỏng, nhập điều kiện rồi nhấn **Nhờ AI chọn bằng chứng**. Báo cáo tự mở và đánh dấu các bằng chứng được AI chọn. Người dùng không cần API key; gói AI miễn phí có hạn mức. Mô hình tham chiếu chưa được kiểm định để dự báo năng suất/tỷ lệ sống ngoài đồng của OM5451.

File chưa ký chứng thư Windows; kiểm tra nguồn tải và SHA256SUMS.txt. Đăng nhập vẫn demo; diễn đàn desktop còn lưu theo máy, chưa phải backend cộng đồng dùng chung.
